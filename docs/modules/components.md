# Components
This module provides a set of components for efficient web building.

## Prerequisites

- CSS
  - Installation of CSS
  - Overwriting CSS
  - CSS variables
  - calc
  - background
  - transition
  - display(flex/flex-box)
  - z-index
  - position
  - pseudo-states(hover)
  - CSS selectors
- HTML
  - tags(div, link:css, button, a)
  - attributes (class, id)

## Installation
    
    ```CSS
    @import ${path to LiOS-Open Installation}/modules/css/components/${your desired module}
    ```
