# Clone Styles

`cloneStyle(sourceNode,targetInstance)` is a static property provided by the [StyleEngine](../style-engine.md) and it takes two parameters `sourceNode` and `targetInstance`.

`cloneStyle` returns a `className` that is scoped to the destination instance.

For example:- 

```JS
const instA = new ui(".instanceA");
const instB = new ui(".instanceB");
const instC = new ui(".instanceC");

const child = instA.child("div");
child.style().set({
    background:"red",
    fontSize:"32px"
});

const copiedStyle = ui.styleEngine.cloneStyle(child,instB); //Copies the style from child to instB and returns a className

const childB = instB.child("div");
childB.class.add(copiedStyle); //Applies the style which was copied from child
```
>The destination don't need to be the root node, it can be any child belonging to the instance
>```JS
>const preMadeChild = instB.child("div");
>const copiedStyle = ui.styleEngine.cloneStyle(child,instB); //Behaves same as previous example
>```

>**Note:** The cloned style is only available to the destination instance and the copied class can be used with multiple nodes in the same instance

> It only copies styles generated by the [StyleEngine](../style-engine.md) and doesn't copy the class names

> The source and destination both needs to be a [nodeMethods](../node-methods.md) instance.
