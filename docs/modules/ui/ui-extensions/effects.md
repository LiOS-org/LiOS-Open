# Effects

This standard extension provides you pre-made configurable CSS effects.

>**Note:** These set of documentations will assume you have installed effects as "effects" as shown below:-
```JS
const effects = liosOpen.uiExtensions.effects;
ui.extend(effects,"effects");

const main = new ui("main");
```

## Available Effects

|Effect|Description|Documentation|
|------|-----------|-------------|
|Frosted Glass| Provides a frosted glass background effect to an element|[Docs](./effects/frosted-glass.md)|
|Text Shadow| Applies a configurable shadow effect to texts|[Docs](./effects/text-shadow.md)|
