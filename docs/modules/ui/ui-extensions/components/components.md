# Components 

`Components` is the `standard extension` that provides you pre-made components for you project.

Some components that the `Components` extension provides are:-

>**Note:** These set of documentations will assume you have installed components as "components" as shown below:-
```JS
const components = liosOpen.uiExtensions.components;
ui.extend(components,"components");

const main = new ui("main");
```
